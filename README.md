# Smartphone Data Code Review

A Python / pandas project that cleans a smartphone dataset and visualises how different features relate to price. It is framed as a **code review exercise**: reviewing a junior colleague's data-prep workflow for a university procurement team (choosing the best phone to offer employees) and getting it ready for production.

## What the project does

- **Cleans the data** (`prepare_smartphone_data`): loads the CSV, keeps only the columns needed for analysis, drops records missing `battery_capacity` or `os`, and converts `price` to a dollar amount (divided by 100).
- **Visualises it** (`visualize_versus_price`): scatter plot of any chosen feature against price, coloured by operating system, with labels generated by a reusable `column_to_label()` helper.
- **Tests it** (`test_nan_values`): a `pytest` unit test (run via `ipytest`) confirming no NaN values remain in `battery_capacity` or `os` after cleaning.

## Code review improvements

- Refactored duplicated plotting code to follow **DRY** principles using `column_to_label()`.
- Fixed the failing unit test so it matches the actual transformation logic in `prepare_smartphone_data()` (it now checks both `battery_capacity` and `os`).
- Confirmed the test suite finishes with `ExitCode.OK`.

## Dataset

`data/smartphones.csv`: 980 smartphones across 46 brands (909 Android, 46 iOS, 11 other) with 22 columns, including price, rating, processor, battery, RAM, storage, screen size, refresh rate, cameras and 5G support.

## Tech stack

Python, pandas, seaborn, matplotlib, pytest, ipytest, Jupyter
